# Design references

Public captures of design references, one markdown file per source. The notes are original analysis: what was taken, what was rejected, and what does not apply. The sites themselves stay theirs.

The format is owned by [capture.md](https://github.com/jonathanjuliani/skilldeck/blob/main/plugins/skilldeck/skills/design/design-inspiration/capture.md) in [jonathanjuliani/skilldeck](https://github.com/jonathanjuliani/skilldeck). Findings, never measurements. Identity never enters a file.

`design-inspiration` in that pack reads this library when a task needs the inspiration store. No clone is required to read: this README is the index, then at most two or three capture files. A checkout is required only to add a capture:

```text
git clone https://github.com/jonathanjuliani/design-references.git ~/.skilldeck-skills/design/library
```

The shipped seed inside skilldeck stays the small starter. This repo is the larger public set. Notes that are not ready to publish stay in `~/.skilldeck-skills/design/references/`.
