## Taken

- A public switch on the create form adds a web sign-up page and a link that can go in WhatsApp. Members keep the normal event. Strangers show up in a Guests tab, separate from member responses.
- A task is a title, a description, and either named people or an open slot with a count. When the count is filled, the task closes. An assigned task stays on "awaiting confirmation" until the person accepts or rejects.
- A deadline, automatic reminders, comments, and who can see responses sit under more settings. The title and the time stay in front.
- For under-18s, the web form is filled by a guardian, with consent. The child is not the account.

## Rejected

- Requiring a large existing group before the public link exists. Help limits the beta to admins of a group of at least 50. A one-off party does not have a club.
- Tasks that only a member with a profile can take. The web guest cannot claim the item. The claim has to work on the same page as the RSVP.
- Creating the public event only in the app. Help says the desktop web can see it and cannot manage it. Fine for a coach with the app. A weak pattern if the host is on a laptop.
- A sign-up fee, which help says is not available yet. This is not a split and not a Pix flow.

## Not applicable here

- Dark mode. It was not described.
- A secret draw.
