## Taken

- A list row is title, date and one sentence. That is enough to choose a post, and nothing competes with the title.
- No thumbnails, tags or reading-time badges on the index. The list is scannable because every row has the same three parts.
- Display and body faces differ sharply in voice (a heavy sans title, a serif body), so title and prose never blur together.
- The post page starts with prose straight after the title and date. There is no cover block to scroll past.
- Dark mode keeps the same structure and only swaps the ground and ink.

## Rejected

- Accent-coloured titles on every row. One hue on every title becomes the page's texture instead of a signal.
- The very narrow single column for an archive that needs tags and search. It works for a short list, not for a filterable one.
- A tip button above the first paragraph. It interrupts the start of the read.

## Not applicable here

- There is no search or tag filter, so the read says nothing about filtering a larger archive.
