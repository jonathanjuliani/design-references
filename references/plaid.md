## Taken

- Calm hierarchy: network scale and jobs (payments, underwriting, fraud, onboarding, PFM) before decorative motion. Sensitive-data products should feel controlled.
- Developer proof appears as real API shape next to the claim “you build the experience.” Code as evidence, not ornament.
- AI is framed as infrastructure behind financial products, not a consumer personality. Fits B2B trust.
- Partner and network density is quantified (institutions, countries). Trust speaks in coverage numbers.

## Rejected

- Loud scroll theatre or playful mascots for bank-data infrastructure. Wrong audience anxiety profile.
- Brand palette and wordmark. Identity.
- Equal feature cards with icons and no job language. Capability names should map to buyer jobs.

## Not applicable here

- Plaid Link and API docs are the product surface for builders. Marketing restraint transfers; Link modal density is a separate read.
